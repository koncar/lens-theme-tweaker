# Theme Tweaker

Recolor Lens to your taste. Start from one of eleven curated presets, adjust any of Lens's 128 color slots live while you watch the app change, and keep the results as themes of your own.

## Features

- **Preset themes**: Lens Dark and Lens Light, Dracula, Nord, Solarized Dark and Light, Gruvbox Dark, GitHub Light, Atom One Light, Tokyo Day and Monokai. One click applies a preset, and the card of the preset in effect is outlined.
- **Quick palette**: eight controls for the surfaces you notice first (window background, main surface, raised panels, borders, sidebar, text). Each one recolors every slot behind that surface at once.
- **All slots**: every color Lens's theme defines, grouped (brand, text, surfaces, buttons, tables, modals, logs, charts and more) and searchable by name. Pick a color with the swatch, or type any CSS color, alpha included. Slots you changed are marked, and each one resets on its own.
- **Dark and light palettes**: one of each, kept separately, so switching between them never loses your edits.
- **Saved themes**: save the current palette under a name, re-apply it later, delete what you no longer want.
- **Export and import**: share a palette as a JSON file, or load one someone shared with you.
- **On or off at any time**: turn Theme Tweaker off to get Lens's own theme back unchanged. Your palettes stay saved.

## Usage

Open **Preferences › Extensions › Theme Tweaker**.

1. Apply a preset, or edit colors under **Quick palette** or **All slots**. Changes show up across Lens immediately.
2. Use **Save as…** to keep the result. **Reset** returns the palette to whatever you last applied (a preset, a saved theme or an import).
3. While Theme Tweaker's colors are on, a small **Theme Tweaker** item sits in the status bar. Click it to come back to the page. To return to Lens's own colors, set **Apply to Lens** to **Off**.

Theme Tweaker paints its palette over the Lens theme chosen in **Preferences › Appearance**. Code editors and terminals keep that theme's colors, so when you use a light palette, also pick a light Lens theme.
